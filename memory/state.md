## النشر — الطريقةُ المجرَّبة

1. **القاعدةُ أوّلاً**: المالكُ يلصق الملفَّ **كما هو** (موصّلُ Supabase لا يصل الإنتاج من هنا)، ثمّ فحصُ السياج.
2. **الواجهةُ بكلمته الصريحة** («ادمج» / «ارفعها للرئيسية»). مصنّفُ الصلاحيات يمنع الدفعَ لـ`main` ما لم يقلها بالدور نفسِه.
   ```bash
   git branch -f deploy-main origin/main && git worktree add <scratchpad>/deploy-wt deploy-main
   cd <scratchpad>/deploy-wt && git cherry-pick <أوّل>^..<آخر>
   git diff --stat deploy-main <الدفعةُ المفحوصة>     # فارغ = الشِفرةُ نفسُها
   git push origin deploy-main:main
   ```
3. **«نزل» بعد قياس الموقع** لا بعد الدفع: `curl https://www.doctorvet.vet/` ⇒ `assets/main-*.js` ⇒ يحمل علامةً
   جديدة (نطاقاً مملوكاً مثلاً `nstk`). Vercel ≈ ١٠ دقائق.

## قواعدُ هذا المالك

- الردُّ بالعراقيّ، ومهارةٌ مناسبة لكلّ طلب.
- رسالةُ الدفعة عربيّةٌ تشرح الجذر، وتنتهي بسطر `Claude-Session:` وحده (لا معرّفَ نموذج).
- قبل كلّ دفعة: `npm run lint`، `npm run build`، `PGBIN=/usr/lib/postgresql/16/bin bash supabase/tests/run.sh` (٣١١٨ فحصاً).
- الميزانيات: الإقلاعُ ٣٥٠٬٥٩٨ (بمفاتيح السحابة) من ٣٥٥٬٠٠٠ بايت؛ `arCold` ٤٩٬٩٩٥ من ٥٠٬٠٠٠ ⇒ **لا مفاتيحَ باردة جديدة**: نطاقٌ مملوك
  (`src/i18n/hot-paths.json` → `owned`).

## البيعُ قبل الجرد (0266) — ما قرّره المالك

- افتراضيّاتٌ منفّذة (يغيّرها إن شاء): المعدودةُ تخرج من الوضع؛ سقفُ ٦٠ يوماً من البداية؛ المشغّلُ يكتب ملاحظة؛
  أوّلُ جرد يختار «خطأ إدخال».
- «شيل الزايد» يقصّ السلّةَ ويقف — الكاشيرُ يرى المجموعَ ويضغط «إتمام البيع» ثانيةً.
- قاعدةُ العيادة: **اعدّ ووافق، ثمّ سجّل الشراء**.
- قبل تشغيلها لعيادة: استعلامُ القياس بـ`docs/neg-stock-plan.md` §٦ (بلا كلفة، كلفةٌ وهميّة < ٢٥٠، سالب، توائم).
- خمسُ مراجعاتٍ عدائيّة؛ الأخيرةُ منخفضةٌ كلُّها. الحدودُ المقبولة: الخطة §٥.

## الكارتون (0267) — ما بلّغ عنه المالك (١٢/١١)

- «باركود الكارتون ما ينمسح»: البيعُ والشراءُ بمسح الكارتون والمغلّف صارا، والمحرّرُ يكتب الحساب. التفصيلُ والحدودُ: `docs/packaging-plan.md` §٧-أ.
- باقٍ (لم يُطلب بعد): الراجعُ الخالص بالكارتون، والجردُ بالكراتين، ورفعُ الأسعار للكارتون المكتوب، ومعدّلُ البيع يعدّ الكارتونَ قطعة.

## أدويةُ العيادة وتصنيفاتُها — طلبُ المالك (١٣/١١)، مرحلتان بقراره

- **م١ (0268، نزلت ١٣/١١)**: العائلاتُ الأربعَ عشرة صفوفٌ بالتصنيفات — تُسمّى وتُرتَّب مع تصنيفات العيادة بقائمةٍ واحدة وتُخفى
  **ويّا أدويتها** (قراره) وترجع من «المؤرشفة». أوّلُ تعديلٍ يبذرها (لا كتابةَ لفتح الإعدادات)؛ قاعدةٌ قبل 0268 ⇒ جملةٌ «يحتاج تحديث».
- **م٢ (لم تبدأ)**: لكلّ دواء — اختياريّاً — سعرٌ للجرعة وكميّتُها وربطٌ بمادّةٍ بالمخزن؛ وكلُّ جرعةٍ تُعطى بالطبلة تصير بيعاً معلَّقاً
  للزبون (لكلّ جرعة، قراره) **ينزل بالسلّة وحده** حين تُفتح بيعتُه، ويخصم من المادّة المربوطة. مصائدُ قيست قبل البدء: سطرُ الطبلة
  نصٌّ بلا معرّف دواء، والمسودّاتُ بالجهاز (فالمعلَّقُ بالخادم)، و`persistMedicalEntries` يكتب الطبلةَ من البيع (حلقةُ احتسابٍ مرّتين)،
  وإلغاءُ إعطاءٍ يعكس، والإعادةُ بمفتاح سطر الطبلة، والفاتورةُ بلا pet/visit.

## أسئلةٌ مفتوحة عند المالك

- نسبةُ الراجع بتبويب «المرتجع» على الفاتورة (تحتاج الخادم + قرارَه بخصم الفاتورة).
- تجاوزُ العرض بالموبايل (٣٩٠): `/retail` ‏١٦٥px، الإعدادات ٦٢px — قديم.
- الحساباتُ التجريبية لأصحاب الحقول ترى «حالات الحقل».
- صلاحيةُ السائق (التوصيل).
- استعلامُ كادرِ عيادةٍ زبونة — معلَّق، وبياناتُه ليست بالمستودع.
- التوستُ يغطّي بطاقاتِ أسفل اليمين بشاشة البيع ٤ ثوانٍ — قديم، لم يُطلب.

## طريقةُ شغلٍ نفعت

- مراجعةٌ عدائيّة بعدسات + موثِّقٍ يحاول نفيَ كلّ ادّعاء، وجولةٌ بعد كلّ تصليح حتى لا يبقى إلا المنخفض.
- كلُّ تصليحٍ بفحصٍ وطفرة تُمسك؛ قسمُ البيع بجذرين (legacy + concurrent)؛ سكربتاتُ المراجعين تُعاد على الشِفرة المصحّحة.
- القياسُ بالأداة الحقيقيّة: LibreOffice (`soffice`، ملفُّ تعريفٍ بالـscratchpad، `LANG=C.UTF-8`)، كروميوم حقيقيّ،
  مستكشفُ ترتيباتٍ للسباقات. ولا حذفَ بـglob خارج الـscratchpad (المصنّفُ يمنعه).
