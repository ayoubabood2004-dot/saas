# خطةُ النموّ العربيّ — أربعُ دفعات

بطلب المالك (٢٥/١٠): موقعٌ لكلّ دولةٍ عربية بلهجتها وأسعارها، وصفحةٌ رئيسيةٌ بمستوى
المواقع الكبيرة بتصنيفاتٍ وتفاصيل كاملة، ودراسةٌ في علم الاقتصاد السلوكيّ ونفسِ المشتري،
وسدُّ ثغرات التسجيل الذاتيّ.

مبنيّةٌ على تسعة تقارير (أربعةٌ تقرأ الشِفرة، وأربعةٌ تبحث بالمصادر، وناقدٌ يكشف التناقض).
الأرقامُ أدناه مقيسةٌ من `dist/` ومن الشِفرة، لا مقدَّرة.

## القراراتُ المعمارية — ولماذا

### ١) الموقعُ التسويقيّ مستندٌ منفصلٌ مولَّدٌ مسبقاً، لا صفحةٌ داخل التطبيق

الصفحةُ الحالية (`Landing.tsx`) صفحةٌ كسولةٌ داخل التطبيق. القياس:

| ما يقيّدها | المقيس |
|---|---|
| فسحةُ حزمة الإقلاع `main` (ومعها CSS التطبيق كلُّه) | **٣٣١ بايت** |
| فسحةُ القاموس البارد `arCold` | **٥ بايت** |
| ما ينزّله الزائرُ قبل أن يرى شيئاً | ~٤١٥ كيلو مضغوطة (التطبيقُ كاملاً: supabase وrepo والطابور) |
| ما يراه Google ومعاينةُ الواتساب | رأسُ `index.html` الإنكليزيّ وحده، والجسمُ دوّارةُ تحميل |

صفحةٌ بتصنيفاتٍ وعشرات الأقسام × لهجات × دول لا تدخل ٣٣١ بايتاً، وكلُّ صنفِ Tailwind
جديد يكبّر CSS التطبيق لكلّ عيادة. فالموقعُ يتبع سابقةَ `store.html`:

- مدخلٌ خاصّ `site.html` + `src/site/` — بلا supabase-js، بلا عامل الخدمة، وCSS خاصٌّ به
  من إعداد Tailwind منفصل (`@config`) فلا يمسّ CSS التطبيق.
- **توليدٌ مسبق (SSG):** بعد `vite build` يُرسم كلُّ مسارٍ لكلّ دولة إلى HTML ثابت
  (`dist/<cc>/…/index.html`) برأسه الخاصّ: `lang="ar-SA"`، العنوان، الوصف، `og:*` بالعربية،
  `canonical`، `hreflang`. فيرى Google والواتساب الصفحةَ كاملةً بلهجتها بلا جافاسكربت،
  ويرسم الزائرُ على شبكةٍ عراقية ضعيفة من أوّل بايت. ثم `hydrateRoot` للتفاعل.
- ميزانيةٌ مضبوطةٌ بحارس `store-weight-guard` كمثل المتجر — تنزل ولا تصعد.

### ٢) المسارات

- `/iq` `/sa` `/ae` `/kw` `/qa` `/bh` `/om` `/jo` `/lb` `/sy` `/ps` `/eg` `/sd` `/ly` `/tn` `/dz` `/ma` `/ye` `/mr` + `/en` (إنكليزيّ عامّ).
- تحت كلٍّ منها: الرئيسية، `pricing`، `features` و`features/<تصنيف>`، `faq`، `security`، `switch` (الانتقال).
- **`/` يبقى جذرَ التطبيق** — العيادةُ المسجَّلة لا يتغيّر عليها شيء (ولا عامل الخدمة، ولا
  إقلاعُ PWA بلا إنترنت). الزائرُ بلا جلسة يُحوَّل بسطرٍ مضمَّن قبل تنزيل الحزمة إلى نسخته:
  اختيارُه المحفوظ ← منطقةُ لغة جهازه ← منطقتُه الزمنية ← `/iq`. **ولا يُحوَّل أبداً** إن حمل
  العنوانُ رمزَ تأكيدٍ أو خطأَ دخول (`#access_token` / `error_code` / `?code=`) — وإلا ضاع تأكيدُ
  الحساب.
- بكلّ نسخة: محوِّلُ «الدولة · العملة» ظاهرٌ بالأعلى، وشريطُ اقتراحٍ يُغلق («يبيّن إنك بمصر —
  تشوف صفحة مصر؟») إن خالف التخمينُ النسخةَ المفتوحة. لا تحويلَ تلقائيٌّ بين الدول.
- عاملُ خدمة التطبيق لا يجيب عن مسارات الموقع (قائمةُ الاستثناء كما `/s/` و`/t/`).

### ٣) اللهجات

عربيةٌ بيضاءُ واضحة أساسٌ لكلّ الشرح والتفاصيل (كما تفعل Foodics وZid)، وطبقةُ لهجةٍ تغطّي ما
يُقنِع: العناوين، الدعوات، الطمأنة، صوتُ الأسئلة الشائعة.

| الطبقة | الدول |
|---|---|
| عراقيّ (بالكاف: «تكدر»، كما يكتب المالك) | العراق |
| خليجيّ أبيض | السعودية، الإمارات، الكويت، قطر، البحرين، عُمان |
| مصريّ | مصر |
| شاميّ | الأردن، فلسطين، لبنان، سوريا |
| العربيةُ البيضاء وحدها | المغرب، الجزائر، تونس، ليبيا، موريتانيا، السودان، اليمن |

الأرقامُ غربيةٌ بكلّ النسخ (سياسةُ التطبيق كلّه).

### ٤) الأسعار: مصدرٌ واحد، والمعروضُ = المقبوض

- العراق: يُعرض **بالضبط** ما تقبضه Wayl (`plan_prices` × `usd_rate` بنفس التقريب) من دالّةٍ
  عامّة `public_pricing()` — والصفحةُ الحالية تعرض ١٥٤٬٠٠٠ وWayl تقبض ١٥٣٬٥٠٠.
- بقية العملات: **أسعارٌ محلّيةٌ يحدّدها المالك** (جدول `plan_local_prices`، تعديلٌ من لوحة المشغّل
  بلا نشر) بأرقامٍ مستديرةٍ طبيعية بدل التحويل اللحظيّ (الجدولُ الثابت فيه أخطاء: سوريا ×١٠٠،
  السودان، اليمن). بلا سعرٍ محلّيّ يُعرض الدولارُ أوّلاً و«≈» بالعملة.
- الدفعُ يُقال كما هو: داخل العراق Wayl بالدينار؛ خارجها لا بوابة بعد — فالنسخةُ تقول ذلك صراحةً
  ولا تعرض شعارَ دفعٍ غير موجود.

### ٥) الصدقُ قاعدةٌ مفحوصة

الادعاءاتُ العشرون الكاذبة أو المبالغة بالصفحة الحالية (تذكيرٌ «آلي»، حدودُ مستخدمين ومساحة
غيرُ مفروضة، «دعمٌ بأولوية» بلا قناة، «صدّر بياناتك متى شئت» بلا تصدير كامل…) لا تنتقل للموقع.
حارسٌ يمنع كلماتٍ بعينها («آلي/تلقائي» عن الإرسال، «الأفضل»، «١٠٠ ضعف»، «بلا إنترنت»…)
ويفشّل البناء على رقمٍ اجتماعيّ بلا مصدر. لا عدّاد وهميّ، لا «آخر ٣ مقاعد»، لا تقييمٌ مختلَق،
لا سعرٌ مشطوبٌ لم يُطلب قطّ.

## الدفعة ١ — الدراسة: اقتصادُ السلوك ونفسُ المشتري

**المخرَج:** دراسةٌ عربيةٌ للمالك (صفحةٌ تُقرأ وتُشارك)، لا كتابٌ نظريّ:
١. من هو المشتري (الطبيب صاحبُ العيادة) وما «الشغلة» التي يستأجر النظام لها.
٢. خمسةٌ وعشرون مبدأً: الآلية، الدليل ودرجتُه (بما فيه ما فشل بالتكرار)، تطبيقُه على صفحتنا
   بنصٍّ عربيّ جاهز، والخطُّ الأخلاقيّ.
٣. الأنماطُ المظلمة وما يحرّمها (القانون والشرع)، وما يختلف بالسوق العربيّ (الثقة الشخصية،
   الواتساب، الوجود الملموس).
٤. ٣٥ تكتيكاً مرتّباً، وقائمةُ «لا تسوّي»، وكيف نقيس بلا تلاعب.
٥. ملحق الأسواق: الدولُ ومجموعاتُها، والعملة، والضريبة، والدفع، ومقترحُ الأسعار — للمالك وحده.

**التحقّق:** مراجعةٌ عدائية لكلّ ادعاءٍ علميّ مقابل مصدره، ولكلّ نصٍّ مقترح مقابل الشِفرة.

## الدفعة ٢ — التسجيل الذاتيّ بلا ثغرة

بالترتيب، وكلٌّ بفحصه:

| # | الثغرة | التصليح |
|---|---|---|
| F1 | رابطُ تأكيدٍ منتهٍ أو مستعمَل يرمي على الصفحة الرئيسية بلا كلمة | قراءةُ `error_code` عند الإقلاع ← `/login` برسالةٍ وزرّ «أرسل من جديد» |
| F2 | الدخولُ ببريدٍ غير مؤكَّد بلا زرّ إعادة إرسال | زرٌّ بالمكان بعدّادٍ تنازليّ |
| F3 | تسجيلُ صاحب الحيوان بالهاتف يرمي «Database error» (عمودا `email`/`full_name` NOT NULL) | هجرةٌ تُصلح المحفّز + فحصٌ بالحزمة لكلّ تركيبة |
| F4 | أخطاءُ Supabase تظهر خاماً بالإنكليزية | مترجمٌ واحد بـ`error.code` لكلّ نداءات المصادقة |
| F5/F6 | إعادةُ التسجيل تفشل بصمت؛ والاستطلاعُ يُخرج الجلسة التي فتحها الرابط | الاستطلاعُ يسأل `getSession` أوّلاً ولا يُخرج أحداً |
| F7 | `signUp` بلا مهلة | مهلةٌ ورسالةُ شبكة كالدخول |
| F8/F9/F10 | الدولةُ «العراق» دائماً، ورمزُ الهاتف لا يتبعها، والصفرُ الأوّل يبقى | الدولةُ من النسخة (`?country=`) ثم التخمين، والهاتفُ يتبعها ويُطبَّع |
| F11/F13 | روابطُ الدخول تفتح بوابةَ أصحاب الحيوانات؛ والدعوةُ رحلةٌ بلا عودة | `as=clinic` على روابط الموقع؛ `next` للدعوة |
| F12/F14 | صفحةُ الدعوة تفقد التركيز مع كلّ حرف؛ وخطأُ البريد يُقال «رمز غير صالح» | تصليحُهما |
| F15 | بذرُ العملة يسابق القراءةَ فيمحو اختيارَ العيادة | البذرُ بعد التأكّد أنّ الخادم فارغ، ومفتاحٌ باسم المستخدم |
| F16 | لوحةٌ فارغةٌ بلا دليل لأوّل يوم | قائمةُ «جهّز عيادتك» تُحسب من الأرقام الحقيقية |
| F17 | لا سياسةُ خصوصية ولا شروط | صفحتان + سطرٌ تحت زرّ التسجيل |
| F19 | اسمُ العيادة يُحفظ اسماً للشخص | يُبذر `clinic_name` |
| F20–F27 | مفاتيحُ ناقصة، `autocomplete`، `dir="ltr"`، رسالةٌ تعيش بعد الاستطلاع، أحداثُ القمع | تصليحٌ مجمَّع |

**بيد المالك (لوحة Supabase — لا تُرى من الشِفرة):** بريدٌ مخصّص (SMTP)؛ فالمدمَج **لا يرسل إلا
لأعضاء الفريق وبرسالتين بالساعة** — إن كان هو الشغّال فكلُّ عيادةٍ غريبة لا يصلها شيء. ورابطُ
الموقع وقائمةُ إعادة التوجيه، وطولُ كلمة السرّ، ورمزُ الستّ أرقام بقالب الرسالة. قائمةٌ مفصّلةٌ
بالتقرير.

## الدفعة ٣ — الموقعُ الجديد

**الهيكل** (مستخلَصٌ من Stripe وHubSpot وProvet وDigitail وFoodics وQoyod وZid):

- **الرأس:** المنتج ▾ (قائمةٌ عملاقة مقسَّمةٌ بيوم العيادة) · الأسعار · ليش دكتور فيت · الأمان ·
  الأسئلة · «الدولة · العملة» ▾ · دخول · [ابدأ ١٤ يوم مجاناً].
- **الرئيسية:** بطلٌ بالنتيجة لا بالوصف + زوجُ دعوات + سطرُ طمأنة صادق · العرضُ التفاعليّ الحاليّ
  (معنوَنٌ «بيانات توضيحية») · «وين عيادتك اليوم؟» (ورق/إكسل، نظامٌ آخر، فروع، صيدلية، دواجن) ·
  ألمٌ ← حلّ بكلمات الطبيب · جولةُ يوم العيادة بتبويبات · ما يميّزنا · الانتقالُ إلينا · الأسعار
  مختصرة · الأمانُ وملكيةُ البيانات · الأسئلة · دعوةٌ أخيرة · تذييلٌ كامل.
- **التصنيفات** (`/features/<…>`)، كلٌّ بصفحته (ألم، كيف يشتغل، القدرات مجمَّعة، شارةُ الباقة،
  أسئلة): السجلُّ الطبيّ والزيارات · الإيواء والعمليات والأقفاص · المختبر · اللقاحات والتذكيرات ·
  الاستقبال والمواعيد · الصيدلية والمخزن · الكاشير · الآجل والتوصيل · المتجر الإلكترونيّ ·
  الواتساب والحملات · بوابةُ صاحب الحيوان والجواز · التقارير · الموظفون والصلاحيات والرواتب ·
  الفروع · حقولُ الدواجن · الطباعة والباركود · الأمان والسجلّ.
- **الأسعار:** شهريٌّ افتراضاً، والسنويّ بتوفيره الحقيقيّ وحده · ثلاثُ باقات بـ«لمن هذه؟» · «بكلّ
  الباقات» · جدولُ مقارنةٍ بنفس التصنيفات · شروطُ التجربة بلا تجميل · كيف تدفع في بلدك · أسئلة.
- **الأمان، الانتقال إلينا، الأسئلة (٣٠+ مجمّعة)، الخصوصية، الشروط.**
- الكتابة: كلُّ قدرةٍ بالموقع لها دليلٌ بالشِفرة (تقريرُ «الحقيقة»)؛ ما هو بلمسةٍ يُقال بلمسة.

**حرّاسٌ جديدة:** تكافؤُ مفاتيح الموقع بين الإنكليزية والعربية وطبقات اللهجة، والكلماتُ الممنوعة،
وميزانيةُ الحجم، ورأسُ كلّ صفحةٍ مولَّدة (lang/canonical/hreflang ذهاباً وإياباً)، والتحويلُ
من `/` لا يمسّ روابطَ التأكيد.

## الدفعة ٤ — النسخُ القُطرية والأسعار

- ملفُّ إعدادٍ واحد لكلّ دولة: اللهجة، العملة وخاناتُها ورمزُها، الضريبة (سطرٌ يقال إن كان صحيحاً
  وحده)، طرقُ الدفع الحقيقية، التواصل (فارغٌ = مخفيّ)، اللغة.
- طبقاتُ اللهجة الأربع يكتبها كاتبٌ لكلّ لهجة، ثم مراجعٌ عدائيّ لكلّ لهجة («هل يكتبها سعوديّ
  هكذا؟»)، ثم حارسُ تكافؤ.
- هجرة: `public_pricing()` (أسعارٌ ودولارٌ للدينار، للزائر) و`plan_local_prices` + تعديلُها من لوحة
  المشغّل، وWayl تقبض السعرَ المحلّيّ بالدينار إن حُدِّد — فيبقى المعروضُ = المقبوض.
- السعرُ يُرسم ثابتاً بالـHTML ساعةَ البناء، ثم يُحدَّث من `public_pricing()` بعد التحميل.
- الدولةُ تنتقل للتسجيل (`?country=SA`) فتنضبط العملةُ ورمزُ الهاتف من أوّل لحظة.
- `sitemap.xml` بكلّ الصفحات وتبادلُ `hreflang`.

## التحقّق والنشر

- كلُّ دفعة: `npm run lint` و`npm run build` وحزمةُ الهجرات، وفحصٌ في المتصفّح (موبايل + سطح
  مكتب، فاتح + داكن)، ومراجعةٌ عدائية قبل الدفع.
- التوجيهُ الثابت على Vercel يُقاس على نشرة المعاينة للفرع قبل `main`.
- الترتيب: الهجرةُ أوّلاً ثم الواجهة. لا دفعَ إلى `main` إلا بكلمة المالك.

## قراراتٌ للمالك (والافتراضُ الذي نمشي عليه حتى يقرّر)

| القرار | الافتراض الآن |
|---|---|
| الأسعارُ المحلّية لكلّ دولة | مقترحٌ بالدراسة؛ الموقعُ يعرض الدولار و«≈» حتى تُحدَّد من اللوحة |
| رقمُ واتساب/هاتف للمبيعات والدعم | فارغ ⇒ لا زرّ (لا رقمَ مخترع) |
| الدفعُ خارج العراق (Tap/Paymob…/تحويل) | الصفحةُ تقول صراحةً: «التجربة متاحة الآن، والدفع نرتّبه معك» فقط إن وُجد رقمُ تواصل؛ وإلا «الدفع الإلكترونيّ متاحٌ داخل العراق حالياً» |
| شهاداتُ عياداتٍ حقيقية بموافقتها | لا قسمَ شهادات حتى توجد |
| عددُ العيادات الحيّ | لا رقم حتى تُقرّ دالّةٌ عامّة وتعريفٌ للعيادة الفعّالة |
| ادعاءاتُ الباقات غير المفروضة (المستخدمون، المساحة، الدعم بأولوية) | تُحذف من الموقع ومن بطاقات الباقات |
| المغرب العربيّ: فرنسية أم عربية | عربيةٌ بيضاء الآن |
| بريدُ التسجيل (SMTP) ورابطُ الموقع بلوحة Supabase | قائمةُ فحصٍ للمالك |
| الدفعُ أثناء التجربة يُضيّع أيامها | يُذكر للمالك؛ تصليحُه منطقُ مال بقراره |
